# Releases

Use the [latest release](https://github.com/Skoczi/vmix-control/releases/latest) for current work. The archived downloads below are preserved as originally built.

Version tags before v19.4 point to the initial repository import, not the original build source. The GitHub-generated “Source code” archives for those tags are **not** historical source snapshots. Download the named ZIP asset for the original build. The initial source archive is provided separately.

Read the [changelog](../CHANGELOG.md) for version notes. [SHA-256 checksums and sizes](releases.json) are included for every archived file.
